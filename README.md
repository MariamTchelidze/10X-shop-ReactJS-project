# 10X Shop

An individual graduation project for a responsive online shop built with React 19, TypeScript, Tailwind CSS v4, React Router, and DummyJSON.

## Run locally

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run typecheck` checks the app and Vite configuration with strict TypeScript.
- `npm run build` type-checks the referenced TypeScript projects and creates a production build.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint.
